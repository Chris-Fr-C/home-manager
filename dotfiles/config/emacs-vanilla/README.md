General keymap concept

leader f -> Find & Search: files, recent, project ripgrep, buffer lines, symbols
leader e -> Explorer: toggle tree explorer / file tree
leader b -> Buffer: switch, kill, revert, list buffers
leader g -> Git: Magit status, git diff, blame
leader c -> Code / LSP: code actions, rename, definitions, diagnostics
leader o -> Org Mode: agenda, capture, TODOs, links
leader w -> Window: splits, navigation, resizing, closing
leader p -> Project: switch project, project root actions
leader h -> Help: describe keys, functions, variables
localleader m -> Mode Specific: trigger buffer-local / major-mode actions
localleader e -> Eval / Execute: evaluate buffer, region, or function
localleader t -> Test: run test at point, file, or test suite
localleader c -> Compile: trigger local build commands
localleader d -> Debug
